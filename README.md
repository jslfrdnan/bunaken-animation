# Project Animasi Grafika Komputer — Bunaken

Video animasi Blender (4 scene, ≥ 30 s/scene) bertema perikanan Pulau Bunaken.
Tugas akhir mata kuliah Grafika Komputer (TIK4041). Deadline 29 November 2026.

| Folder | Isi | Di git? |
|---|---|---|
| `blender/` | `scene1.blend` … `scene4.blend`, `aset.blend` (library yang di-link ke tiap scene) | Tidak (OneDrive) |
| `skrip/` | Skrip Python Blender (generator terrain, boids, utilitas aset) | Ya |
| `render/sceneN/` | Hasil render per scene | Tidak |
| `referensi/` | Frame referensi video *Coding Adventure: Boids* | Gambar saja |
| `aset/unduhan/` | Aset publik yang diunduh manual (Poly Pizza dll.) | Tidak |
| `audio/` | Narasi, musik, SFX | Tidak |
| `edit/` | Proyek editing video | Tidak |

Spesifikasi render: Blender 5.2.2 LTS, EEVEE, 1920×1080, 24 fps.
Kredit aset publik dicatat di catatan Obsidian "Aset & Teknik".
